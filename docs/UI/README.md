# PharmaCore — UI & Frontend Architecture

## 1. Overview

PharmaCore delivers an accessible, bilingual, and responsive user interface built on **React 19**, **Next.js 15 Pages Router**, and **Tailwind CSS**. The frontend embraces progressive enhancement, responsive touch targets, and full Arabic RTL / English LTR directional layouts.
